# 主动发言台

在 AstrBot WebUI 的插件页面里，手动触发 Bot 主动说一句。

## 功能

- 扫描最近活跃的会话（群聊 / 私聊），也可以手动填写 UMO
- 内置 6 套预设提示词：接话、群聊破冰、阴阳吐槽、关心近况、撒娇卖萌、晚安
- 支持自定义提示词与补充要求
- 预设可在页面内新增、编辑、删除，保存在 `data/plugin_data/astrbot_plugin_proactive_button/presets.json`

## 生成方式

插件**不自己调用 LLM、也不自己发送消息**。触发时它会构造一条内部消息并提交到
AstrBot 的事件总线，由原生回复管线处理，因此：

- 使用当前会话的人格和对话历史
- 走正常的 LLM 工具循环
- 遵循全局消息防抖、分段回复、表情包、TTS、内容安全检查等既有规则
- 消息由平台适配器正常发送，`after_message_sent` 等钩子照常触发

代价是：这条内部消息会像普通用户消息一样进入会话历史，后续聊天能看到它。

## 使用

1. AstrBot WebUI → 插件 → 主动发言台 → 页面
2. 选择目标会话
3. 选择一个预设（或自定义）
4. 点击「立刻触发」
5. 在「最近触发」里查看结果

## 配置

- `enabled`：总开关
- `cooldown_seconds`：同一会话冷却时间，默认 5 秒
- `response_timeout_seconds`：等待回复的超时时间，默认 180 秒

## 已知交互

- 消息防抖插件可能让这次触发延迟约 10 秒；如果期间同一会话来了新消息，防抖可能合并或取消它。
- 群聊触发时，内部消息的发送者取 `admins_id` 里的第一个账号；私聊取会话对象本身。
